# Void Drift — 무기 획득 / 레벨 / 3choice 등장 로직

> onepage-design.md 파생 과제 "무기 '추가' 획득 방식 → 3choice 풀 등장 로직".
> upgrade-pool.md의 무기/파워 목록을 전제로 함. 3choice 발생 리듬은 progression-design.md 참조.

## 1. 발사 모델 — "추가"의 의미

무기는 교체가 아니라 **보유(추가)**.
> 보유한 무기 전부가 **각자 고유 연사속도로 동시 오토 발사**.

- 기관총 → 유도 미사일 뽑으면 둘 다 발사 → 레일건까지 뽑으면 셋 다 발사.
- 무기 3종뿐이라 슬롯 압박 없음. 한 판에 다 모으고 키우는 걸 전제.

## 2. 시작 로드아웃

- **기관총** (기본 무기, Lv1)
- **실드 스킬** (시작부터 보유 — 전용 버튼 항상 존재)

## 3. 무기 레벨 시스템 (Lv1~5)

무기 카드를 뽑을 때마다 레벨업. 처음 = 획득(Lv1), 재픽업 = 레벨업.

| 레벨 | 효과 |
|---|---|
| Lv1 | 무기 획득 (탄약 1발) |
| Lv2 | 탄약 2발 |
| Lv3 | 탄약 3발 |
| Lv4 | 탄약 4발 (**탄약 최대**) |
| Lv5 | **무기별 특수 기능** |

> "탄약"은 동시 발사 탄/줄기 수. 기존 "멀티샷 파워"는 제거되고 이 레벨업으로 통합.

### Lv5 특수 기능
| 무기 | 특수 기능 |
|---|---|
| 기관총 | 연사속도 +20% (기본 연사에 추가) |
| 유도 미사일 | 단일 피해 → **약간의 범위 피해** 추가 |
| 레일건 | **관통 효율** — 관통 시 데미지 감소를 완화 (예: 히트당 -30% → -15%, 값 미정) |

### 레일건 3축 (독립)
1. **탄약(레벨 1~4)**: 동시 발사 레일 줄기 수 (다른 무기와 동일 규칙)
2. **최대 관통 수**: 한 줄기가 일렬로 뚫는 몹 수 (2 = 2마리까지 타격), **최대 5** — 레벨 무관 별도 스택 파워
3. **관통 효율(Lv5)**: 관통할수록 데미지 감소하는 기본 속성을 완화

## 4. 무기 픽업 등장 리듬

- 무기 카드는 **플레이어 레벨 5마다**(Lv5, 10, 15…) 등장.
- 그 마일스톤의 3choice엔 **무기 카드 최소 1개** 보장(최대 3까지 가능), 나머지는 일반 스탯.
- 그 외 일반 레벨업 = 스탯/파워 강화만 (무기 카드 없음).
- 마일스톤 무기 카드 후보: 미보유 무기 = 획득(Lv1) / 보유 무기 = 레벨업(≤Lv5). **Lv5 도달 무기는 제외**.

## 5. 3choice 등장 자격 규칙

| 카드 종류 | 등장 조건 |
|---|---|
| 무기 픽업/레벨업 (기관총/유도/레일건) | **5레벨 마일스톤에만**, 최소 1개 보장. Lv5 도달 무기 제외 |
| 무기 파워 (공격력 / 연사속도 / 탄속 / 최대 관통 수) | 해당 무기 보유 시, 일반 레벨업에 등장 |
| 공용 스탯 (이동속도 / 최대체력 / 체력재생 / 오브 획득범위 / 오브 가치) | 항상 |
| 실드 스킬 강화 (쿨다운 / 지속 / HP) | 항상 (시작 보유) |
| 최대 스택/레벨 도달 항목 | 풀에서 **제외** |

## 6. 추첨 방식

- 자격 있는 항목 중 **가중치 기반으로 서로 다른 3개** 추첨.
- 일반 레벨업: 무기 파워 + 공용 + 스킬 강화 중 추첨.
- 마일스톤 레벨업: 무기 카드 1개 확정 + 나머지 2개 일반 추첨(또는 무기 카드 추가).
- 엣지: 자격 항목이 3개 미만인 경우 처리(중복 허용 or 빈 슬롯) — 추후 확정.

## 7. 3choice 가중치 관리 — 적 조합 툴과 **분리**

- 3choice 풀(플레이어 성장 밸런싱)과 적 스폰 풀(적 조합 오서링)은 **다른 도메인**. 한 툴에 묶지 않음(관심사 분리).
- 3choice 가중치가 필요하면 **별도 소형 데이터(ScriptableObject / 간단 테이블)** 로 충분. 메인 에디터 툴 어필은 적 조합 쪽.

## 8. 확정 요약

- 발사: 보유 무기 전부 동시 오토발사 (각자 연사속도)
- 시작: 기관총(Lv1) + 실드
- 무기 레벨 1~5: Lv1~4 탄약↑(최대 4), Lv5 무기별 특수
- 무기 카드는 5레벨 마일스톤에만 등장(최소 1 보장)
- 3choice: 자격 규칙 기반 서로 다른 3개 가중 추첨, 최대치 제외
- 3choice 가중치는 적 툴과 분리된 별도 소형 데이터

## 9. 남은 과제

- 3choice 가중치 초기값 / 무기 카드 마일스톤 가중치 (Day5)
- 무기 카드가 마일스톤에만 등장하는 규칙 최종 확인
- 자격 항목 3개 미만 엣지케이스 처리 확정
- 다중 무기 동시 발사 시 모바일 성능(탄 오브젝트 풀링) — 구현 단계 고려
