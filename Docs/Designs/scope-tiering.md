# Void Drift — 스코프 티어링 (MVP)

> 마감 2026-08-31. 기획 풍부함 ≠ 전부 구현. 구현 우선순위를 Must/Should/Nice로 분리.
> 빌드 순서: **Must 먼저 → Should → Nice**. 마감 압박 시 Nice부터 잘라낸다.

## 판단 기준
포폴 목적 = ① UI Toolkit **에디터 커스텀 툴 실증**(공고 1순위) ② **플레이 가능한 데모** ③ **모바일 빌드**.
"이 목적에 필수인가?"로만 티어를 가른다.

## 🔴 Must — 없으면 포폴 실패

- **코어 루프**: 상대 드래그 이동 + 오토 사격(기관총) + 적 스폰/접근 + 오브 드랍·습득(자석) + 경험치 레벨업 + 3choice(일시정지) + HP/게임오버 + 우측 상단 HUD
- **에디터 커스텀 툴 (핵심 어필)**: 적 조합 오서링(비주얼×이동AI×공격AI×스탯) + **유효성 경고**(교전거리 모순) + ScriptableObject DB + Addressables Group/Label 연동 + 최소 스폰 연결
- **최소 적 다양성**: 이동 AI 2종(직진/추적) × 공격 AI 2~3종(충돌/탄막/자폭), 아키타입 2~3
- **최소 3choice 풀**: 공용 스탯 몇 종(공격력/이동속도/최대체력) — 빌드 선택이 성립할 최소
- **모바일 가로 빌드** (Android)

## 🟡 Should — 있으면 확실히 강해짐

- **무기 3종** (유도 미사일 / 레일건) + **무기 레벨 Lv1~4**(탄약↑)
- **무기 마일스톤**(플레이어 5레벨마다 무기 카드)
- **실드 스킬**(전용 버튼) + 강화 3종(쿨다운/지속/HP)
- **난이도 페이즈**: 구간 전환 + 스폰 프로파일 교체 + "공허 속 적이 더욱 강해졌습니다" 안내 문구
- **에디터 툴 2~3층**: 아키타입 프로파일 가중치(반쯤 묶기), 스폰 풀 시간축 타임라인
- **적 AI 풀세트**: 견제(호버)/사행/조준단발, 9개 에셋 버킷
- **업그레이드 풀 풀세트**: 탄속/최대 관통 수/체력재생/오브 획득범위·가치
- **로컬 하이스코어** 저장
- **피격/파괴 VFX**(빨간 깜빡 — 원페이지 차별점)
- **데모 영상** (포폴 제출용)

## 🟢 Nice — 시간 남으면

- **무기 Lv5 특수기능** 3종 (기관총 연사+20% / 유도 범위피해 / 레일건 관통 효율)
- 레일건 관통 데미지 감소·효율 디테일
- 데미지 넘버(월드스페이스 UI)
- 사운드 / BGM
- 우주 로우폴리 비주얼 폴리싱
- **Firebase 리더보드 연동**

## 메모
- 에디터 툴이 공고 1순위라 Must의 무게중심. 게임 자체는 "툴로 만든 콘텐츠가 실제로 도는 데모" 수준이면 목적 달성.
- 무기 Lv5 특수·레일건 관통 디테일은 Nice라, 그 수치·세부 미정이어도 마감 지장 없음.
