## 1. 플랫폼 / 자세

- **모바일, 가로형(landscape)**

  (폰을 한 손으로 들고, 조작손 한 손으로 기동)

### 왜 모바일 유지인가 (전략)
- 타깃 그라비티(판교 DevHub) = 모바일 중심 퍼블리셔, 국내 시장도 모바일 선호.
- 포폴에 모바일 빌드가 1개뿐 → 모바일 = 포폴의 전략적 가치. 컨트롤 난이도로 버릴 이유 없음.

## 2. 입력 매핑

| 입력 | 방식 (모바일=주) | PC 보조 | 비고 |
|---|---|---|---|
| 이동 | **방향형 플로팅 조이스틱** (화면 어디서든, §3) | **WASD / 화살표** | 조이스틱과 공존·합산. PC 빌드는 마우스 이동 차단(§5.5) |

## 3. 이동 — 방향형 플로팅 조이스틱 (밸런싱 패스 2026-08-22 전환)

> **변경**: 초기 "상대 드래그" 확정(아래 폐기 블록)을 **방향형 플로팅 조이스틱**으로 뒤집음(사용자 결정).
> 상대 드래그는 손가락을 멈추면 기체도 멈춰, "그 방향으로 계속 가고 싶다"는 조작감과 어긋났다.

- 화면 임의 지점 터치 → **누른 지점에 베이스(조이스틱)가 뜬다**(플로팅). 노브를 민 **방향+거리(세기)가 곧 속도**.
- **스틱을 유지하면 그 방향으로 계속 이동**, 떼면 정지. 살짝 기울이면 느리게(세기 비례).
- **절대좌표 폐기 사유는 그대로 회피**: 빈 곳을 눌러 방향만 주므로 기체가 손가락 밑에 가려지지 않는다.
- **구현**: 가상 스틱 단일 소스 = `VD.UI.JoystickView`(입력+시각, `Value`=단위 원반). `VD.Player.PlayerMovement`가
  `Value`를 읽어 이동(키보드와 동일 뷰포트 파이프라인·합산). Sci-Fi UI `joystick.png`/`joystick_back.png` 사용.
- **플랫폼 게이트**: 에디터/모바일에서만 포인터 이동 활성 → **PC 스탠드얼론 빌드는 마우스 이동 차단**(§5.5 키보드만).
- 파라미터(`pointerMoveSpeed` / `knobRadius` / `deadZone01`)는 Day5 튜닝.

> ~~**[폐기] 상대 드래그**~~ — 화면 임의 지점 터치 → 드래그 델타만큼 기체가 상대 이동(`dragGain`). 손가락 정지 시 기체 정지.
> 절대좌표는 "기체가 손가락에 가려짐"으로 폐기했었음. **상대 드래그도 위와 같이 방향형 조이스틱으로 대체됨(2026-08-22).**

## 4. 실드 스킬 — 전용 버튼 (더블탭 폐기)

- **더블탭 방식 폐기 사유**: 이동 드래그 중 더블탭이 밀림·오터치로 오작동 위험.
- **전용 버튼** 채택: discoverable + 오작동 없음 + 별도 입력 인식 시스템 불필요.
- 배치: 가로 화면 코너(조작손 반대편 또는 조작손 엄지 근처). 좌/우 배치는 옵션화 검토.

> 이 결정으로 "이동 드래그와 분리된 더블탭 입력 시스템" 파생 과제는 해소됨.

> **구현됨(M4-4)**: 코너 버튼(HUD 우하단, `ShieldButtonView`) + **Space**(PC 보조) 동일 발동. 실드 성격·강화는 [upgrade-pool.md](upgrade-pool.md) §5. 버튼 위치 좌/우 옵션은 미정(§7).

## 5. 화면 레이아웃 (가로) — 초안

- 이동: **플로팅 조이스틱**(화면 어디든 누른 지점에 등장, §3) — 눌린 동안만 표시

## 5.5. PC 보조 입력 (모바일 원칙 유지, 데스크톱 플레이 보조)

- **원칙은 모바일**(§1). PC 입력은 에디터/Standalone에서 플레이·검증을 쉽게 하기 위한 **보조**이며 모바일 조작을 대체하지 않는다.
- **이동 = WASD / 화살표**: 조이스틱과 **공존(합산)**. 같은 이동 파이프라인(타깃 뷰포트 → 경계 클램프 → 속도 매핑)에 방향 입력을 더하는 방식이라 경계·일시정지 정합이 동일하게 적용된다. 속도는 파라미터(초당 뷰포트 분율, Day5).
- **마우스(포인터) 이동 = 에디터/모바일 한정**: 방향형 조이스틱은 **에디터·모바일에서만 활성**(테스트 편의+모바일 실사용). **PC 스탠드얼론 빌드에선 마우스 이동이 차단**되고 키보드만 유효(`Application.isEditor || Application.isMobilePlatform` 게이트).
- **실드 = Space**: 코너 전용 버튼과 **동일한 발동**을 공유(입력만 둘, 로직은 하나). 실드 메커니즘은 M4-4.
- **입력 백엔드**: New Input System **직접 디바이스 읽기**(`Keyboard.current`/`Pointer.current`, 액션 에셋 미사용). 레거시 `Input.*` 미사용.
