## 1. 개요

오브를 일정량 습득할 때마다 3개 선택지 중 1개를 즉시 적용(뱀서라이크 문법).
강화는 **스택형(누적)** 과 **언락형(1회 획득)** 을 혼합한다.

- **무기(레벨형)**: 무기 종류 획득 후, 같은 무기 재픽업으로 **레벨업**(탄약↑, Lv5 특수기능). 교체 아님, 추가. → 상세는 [weapon-acquisition.md](weapon-acquisition.md)
- **스택형**: 공용/무기별 스탯 강화. 반복 획득 시 누적.

## 2. 무기 (탄약 종류) — 레벨형

무기는 서로 교체가 아니라 **동시 보유(추가)** + 재픽업으로 **레벨업**(→ [weapon-acquisition.md](weapon-acquisition.md)).

| 무기 | 성격 | 비고 |
|---|---|---|
| 기관총 | 기본탄, 직선 연사 | 시작 무기(Lv1) |
| 유도 미사일 | 적 자동 추적 | 단일 피해(Lv5서 범위 추가) |
| 레일건 | 레이저형, 일렬 관통 | 탄속 없음. 탄약(줄기 수)·관통 수·관통 효율 3축 |

## 3. 탄약 파워 — 무기별 적용 매트릭스 (스택형)

파워마다 무기별 적용 여부가 다르다.

| 파워 | 기관총 | 유도 미사일 | 레일건 |
|---|:---:|:---:|:---:|
| 공격력 | ✅ | ✅ | ✅ |
| 연사속도 | ✅ | ✅ | ✅ |
| 탄속 | ✅ | ✅ | ❌ (해당 없음) |
| 최대 관통 수 | ❌ | ❌ | ✅ (한 줄기가 뚫는 몹 수, 최대 5) |

> **탄 수(탄약)는 파워 스탯이 아니라 무기 레벨업으로 증가** (Lv1~4, 최대 4발 동시).
> 멀티샷 강화 카드는 제거됨 → 무기 레벨로 대체. 상세: [weapon-acquisition.md](weapon-acquisition.md).
> 파워 스탯은 무기별로 스코프됨(해당 무기 보유 시에만 3choice 등장).

## 4. 기동 / 생존 / 유틸 (스택형)

| 대분류 | 아이템 | 효과 요약 |
|---|---|---|
| 기동 | 이동속도 | 기체 이동속도 ↑ |
| 생존 | 최대체력 | 최대 HP ↑ |
| 생존 | 체력재생 | 초당 HP 회복 |
| 유틸 | 오브 획득범위 | 자석 반경 ↑ |
| 유틸 | 오브 가치 | 오브당 자원량 ↑ |

> 피격판정 축소: 제외(플레이어에게 혼란).

## 5. 액티브 스킬 — 실드

게임 내 **유일한 액티브 스킬**. (다른 스킬은 5일 스코프상 제외)

- **발동**: 전용 버튼(가로 화면 코너). 시작부터 보유. → [controls-design.md](controls-design.md)
- **성격**: 자체 HP를 가진 방어막(피격 후 무적 프레임 아님).
- **강화(스택형) 3종**:
  - 쿨다운 감소
  - 지속시간 증가
  - 실드 HP 총량 증가

## 6. 확정 목록 요약

- 무기(레벨형 Lv1~5): 기관총 / 유도 미사일 / 레일건 — **3종** (Lv1~4 탄약↑, Lv5 특수)
- 탄약 파워(스택): 공격력 / 연사속도 / 탄속 / 최대 관통 수(레일건) — 무기별 적용
- 기동(스택): 이동속도
- 생존(스택): 최대체력 / 체력재생
- 유틸(스택): 오브 획득범위 / 오브 가치
- 스킬 강화(스택): 실드 쿨다운 / 지속 / HP

## 7. 남은 과제

- 각 항목 실제 수치 / 스택당 증가폭 / 최대 스택 (Day5 튜닝, 테이블 툴 컬럼화)
- 레일건 관통 데미지 감소율 / 관통 효율 수치 (Day5)
