## 1. 3choice 발생 리듬 — 확정

오브 = 경험치. 뱀서라이크의 경험치-레벨업 구조.

- **오브 습득 → 경험치 게이지 누적 → 임계값 도달 시 레벨업 → 3choice 팝업.**
- **임계값: 점증형** — 레벨 오를수록 필요 오브량 증가(초반 강화 자주, 후반 뜸). 성장 페이스 조절.
- **선택 중: 일시정지** — 게임 프리즈 후 고르고 재개. 모바일 한 손 조작에 안전, 오터치 없음.

### 무기 마일스톤
- 플레이어 레벨 **5마다**(5,10,15…) 3choice에 **무기 카드 최소 1개** 등장.
- 그 외 레벨업은 스탯/파워 강화만. (상세: weapon-acquisition.md §4~5)

## 2. 난이도 곡선 — 확정

**기준: 시간 기반** (무한 전진 속도 일정 → 시간 == 거리, 생존시간이 곧 점수).
**방식: 혼합(연속 + 구간)** — 시간축을 **페이즈**로 분할.

- **페이즈 내부**: 스탯 배율(적 체력/속도/데미지) **아주 미세하게** 연속 상승.
  유저가 거의 못 느낄 정도("어? 뭐지?" 수준).
- **페이즈 경계**: (1) 스폰 프로파일 전환(순한 조합 → 위협 조합) + (2) 배율 눈에 띄게 점프
  → 기존 대비 **꽤 강해진 체감**.
  - **경계 안내 문구** 표시 (예: "공허 속 적이 더욱 강해졌습니다") — 체감을 명시적으로 각인. (uGUI HUD)

### 두 파트
| 파트 | 내용 | 관리 |
|---|---|---|
| 전역 스탯 배율 | 시간에 따른 체력/속도/데미지 배율. 페이즈 내 미세, 경계서 점프 | 곡선 데이터 |
| 스폰 프로파일 타임라인 | 페이즈(시간 구간)별 적 조합 프로파일·밀도·가중치 | **에디터 스폰 풀 = 툴 핵심** |

> 이 타임라인이 곧 enemy-design.md 3층 "스폰 풀"의 **시간축**.
> 적 툴이 "조합 정의 + 시간대별 큐레이션"까지 커버 → 어필 확대.

수치(페이즈 길이 / 내부 상승률 / 경계 점프폭)는 Day5 튜닝.

## 3. 종료 조건 / 점수 — 확정

- **종료**: HP 0 → 게임오버 → 결과 기록.
- **점수 = 생존시간 + 적 처치별 점수** (간단하게).
  - 적 처치 점수: 적 종류마다 점수값 → **적 테이블 툴 필드**로 관리 (enemy-design.md §7).
- **인게임 표기**: **우측 상단 간단 HUD** (생존시간/점수). UI/UX엔 힘 최소 투자.
- **기록 저장**: **로컬만** (PlayerPrefs 수준 하이스코어).
  - **Firebase 연동(리더보드)**: 시간 되면 — **Nice 티어**.

## 4. 확정 요약 (현재까지)

- 오브 = 경험치, **점증형 임계값**, 레벨업 시 3choice, **선택 중 일시정지**
- 무기 카드는 5레벨 마일스톤에만 (최소 1 보장)
- 난이도: **시간 기반 + 페이즈 혼합** — 페이즈 내 미세 상승, 경계서 프로파일 전환 + 점프 + 안내 문구
- 종료: HP 0. 점수 = **생존시간 + 적 처치별 점수**, 우측 상단 HUD, 로컬 저장(Firebase는 Nice 티어)

## 5. 남은 과제

- 레벨별 임계값 곡선 / 페이즈 길이·상승률·점프폭 실제 수치 (Day5)
- 적 종류별 점수값 (Day5, 적 테이블)
